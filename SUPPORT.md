# Support

| Need | Where to ask |
| --- | --- |
| Reproducible defect | [Bug report](https://github.com/Blucezhang/micro-server-own/issues/new?template=bug_report.yml) |
| Focused product or engineering proposal | [Feature request](https://github.com/Blucezhang/micro-server-own/issues/new?template=feature_request.yml) |
| Usage question or design trade-off | [GitHub Discussions](https://github.com/Blucezhang/micro-server-own/discussions) after it is enabled |
| Security-sensitive concern | Ask the maintainer for a private reporting channel; do not include exploit details in a public issue |

When asking for help, include the module, environment, exact command or request, expected result, actual result, and sanitized logs. Never post passwords, tokens, payment identifiers, or production customer data.
